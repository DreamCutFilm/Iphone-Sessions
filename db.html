Відкрити SQL Editor у Supabase →

Що робити

  1. Тапни «Копіювати схему»
  2. Тапни «Відкрити SQL Editor»
  3. Тапни у велике порожнє поле, тримай палець → Вставити
  4. Кнопка Run
  5. Має зʼявитися Success. No rows returned

Наявні дані не постраждають: файл написаний так, щоб виконуватись повторно скільки завгодно разів.
