# DreamCut Ops

Робочий інструмент оператора для iPhone: проєкти, дедлайни, задачі, нагадування,
ідеї та кінорозрахунки в одному застосунку. Працює офлайн, дані не залишають
пристрій.

Це PWA — вебзастосунок, який ставиться на екран «Додому» і поводиться як
звичайний застосунок: своя іконка, повний екран, робота без інтернету.
Побудований так, щоб згодом стати нативним застосунком через Xcode — див.
[docs/NATIVE.md](docs/NATIVE.md).

## Як поставити на iPhone

1. Відкрий адресу застосунку в **Safari** (саме в Safari — Chrome на iOS не
   вміє додавати на екран «Додому»).
2. Кнопка «Поділитися» → **На екран «Додому»**.
3. Запускай з іконки. Далі інтернет не потрібен.

## Публікація

Хостинг — **GitHub Pages**, увімкнений через GitHub Actions
(`.github/workflows/pages.yml`). Збирати нічого не треба: репозиторій
викладається як є, але спершу проганяються тести — зламана формула не має
доїхати до телефона непоміченою.

Щоб це працювало, у налаштуваннях репозиторію потрібно один раз обрати
**Settings → Pages → Source: GitHub Actions**. Далі кожен push у робочу гілку
оновлює застосунок автоматично.

Порожній файл `.nojekyll` у корені вимикає обробку Jekyll: інакше GitHub міг
би проігнорувати файли й теки, назви яких починаються з підкреслення.

## Що всередині

### Робота

- **Проєкти** — стадії від заявки до здачі, клієнт, локація, гонорар,
  знімальні дні, дата здачі матеріалу.
- **Задачі** — терміни, пріоритети, привʼязка до проєкту, нагадування.
- **Нагадування** — спливають, поки застосунок відкритий, і наздоганяють при
  наступному запуску. Обмеження вебу на iOS описане нижче.
- **Ідеї** — швидкий блокнот із тегами й пошуком.
- **Календар** — знімальні дні, дедлайни й задачі однією стрічкою.

### Мова та валюта

У налаштуваннях обирається валюта гонорарів: гривня, злотий, долар або євро.
Це налаштування показу — суми в базі лежать числами без прив'язки до валюти,
тому перемикач **не конвертує** вже введені гонорари за курсом. Так історія
проєктів лишається такою, якою її вводили.

Там же обирається мова інтерфейсу. Зараз готова українська; польська присутня
у списку, її вибір зберігається, але тексти ще не перекладені — інтерфейс
лишається українським, доки переклад не додадуть.

### Розрахунки

| Інструмент | Що рахує |
|---|---|
| Глибина різкості | Гіперфокал, ближня й дальня межі, зона перед і за обʼєктом |
| Кут огляду | Кути, покриття кадру на дистанції, підбір фокусного під крупність |
| Затвор і швидкість | Кут затвора ↔ витримка, уповільнення при рампі частоти |
| ND і стопи | Щільність, кратність, різниця між діафрагмами |
| Карти памʼяті | Обсяг зміни за кодеком, кількість карт, час на карту |
| Таймкод | Тривалість, сума, різниця, коректний drop-frame для 29.97 і 59.94 |
| Золота година | Схід, захід, золоті й сині години — астрономічно, без інтернету |

Довідники сенсорів (від Super 16 до RED VV) і кодеків (ProRes, BRAW, ARRIRAW,
камерні) — у `src/core/cine/`.

## Дані

Усе зберігається локально в браузері й нікуди не надсилається — застосунок
взагалі не має мережевого коду.

Зворотний бік: сховище браузера не вічне. Очищення даних Safari, зміна
телефона чи видалення застосунку зітруть базу. Тому в налаштуваннях є
**резервна копія** — один JSON-файл, що зберігається у «Файли» чи iCloud
Drive. Роби її після великих змін. Той самий формат читатиме майбутня
нативна версія.

## Обмеження, про які варто знати

- **Нагадування.** Веб на iOS не може надійно розбудити застосунок, коли він
  закритий — для цього потрібні push-сповіщення з сервером. Нагадування
  спрацьовують, поки застосунок відкритий, і показуються при наступному
  запуску. Для критичних речей дублюй у стандартні «Нагадування». Нативна
  версія знімає це обмеження повністю.
- **Розрахунок сонця** не враховує рельєф і погоду — тільки астрономію.
- **Бітрейти кодеків** зі змінним потоком (BRAW, R3D, H.265) приблизні, тому
  в калькуляторі закладено запас у відсотках.

## Розробка

```bash
npm test        # тести розрахункового ядра (Node, без браузера)
npm start       # локальний сервер на http://localhost:8080
npm run icons   # перегенерувати іконки (потрібен Python і Pillow)
```

Збірки немає — це нативні ES-модулі, які браузер вантажить напряму. Після
зміни файлів застосунку підніми `VERSION` у `sw.js`, інакше пристрої
показуватимуть стару версію з кешу.

### Структура

```
index.html            каркас сторінки
sw.js                 service worker: офлайн-кеш
manifest.webmanifest  опис застосунку для «На екран Додому»

src/core/             ядро без DOM — переноситься в нативний застосунок як є
  storage.js          адаптер сховища (точка заміни для нативу)
  store.js            стан застосунку
  models.js           проєкти, задачі, ідеї
  selectors.js        похідні вибірки: що горить, що сьогодні
  dates.js            дати без пасток часових поясів
  backup.js           експорт та імпорт
  cine/               кінорозрахунки

src/ui/               інтерфейс
  views/              екрани
  reminders.js        нагадування (точка заміни для нативу)

tests/                тести ядра
tools/make-icons.py   генератор іконок
docs/NATIVE.md        як зробити нативний застосунок через Xcode
```

Межа між `core` і `ui` жорстка: у `core` немає жодного звертання до DOM.
Саме тому тести ядра виконуються в Node, а перехід у Xcode не потребує
переписування формул.
